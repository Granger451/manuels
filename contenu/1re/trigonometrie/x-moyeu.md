**Question 3 :**

- Une formule de tableur commence par **=**.
- Pour multiplier deux nombres dans une formule, on utilise le symbole `*`.
- Le nombre $\pi$ s'écrit **PI()** dans une formule.
- Le cosinus s'écrit **COS()** dans une formule.
- Le sinus s'écrit **SIN()** dans une formule.
