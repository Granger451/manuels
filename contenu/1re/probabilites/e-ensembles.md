---
titre: "Déterminer l'intersection et la réunion de deux ensembles"
type: "exercice"
---

On considère les trois ensembles de nombres suivants :

- $A = \{1 ; 4 ; 5 ; 7 ; 8\}$
- $B = \{1 ; 3 ; 5 ; 6 ; 9\}$
- $C = \{2 ; 3 ; 9\}$

1. Donner les éléments de l'ensemble $A \cap B$.

2. Donner les éléments de l'ensemble $B \cap C$.

3. Donner les éléments de l'ensemble $A \cup C$.
