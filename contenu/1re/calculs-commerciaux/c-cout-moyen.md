---
titre: "Coût moyen"
type: "connaissance"
---

**Définition :** le coût moyen $C_M$ représente le coût unitaire. C'est le rapport entre le coût de production $C(x)$ et le nombre d'unités produites $x$.

**Formule :** $C_M(x) = \frac{C(x)}{x}$ avec $x$ non nul

**Exemple**

Une usine produit des téléviseurs et le coût de production est modélisé par la fonction $C$ telle que : $C(x) = 2x^2 + 2x + 1000$ où $C(x)$ est le coût de production pour $x$ unités produites.

On souhaite connaître le coût moyen pour la fabrication de 20 téléviseurs.

On utilise la formule : $C_M(x) = \frac{2x^2 + 2x + 1000}{x}$.

On simplifie : $C_M(x) = 2x + 2 + \frac{1000}{x}$.

On utilise cette fonction pour calculer le coût moyen de la fabrication de 20 téléviseurs :

$C_M(20) = 2 \times 20 + 2 + \frac{1000}{20}$

$C_M(20) = 40 + 2 + 50$

$C_M(20) = 92$

Le coût moyen de production pour la fabrication de 20 téléviseurs est donc de 92 euros par téléviseur.
