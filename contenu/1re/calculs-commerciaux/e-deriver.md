Déterminer la fonction dérivée des fonctions suivantes.

- $f_1(x) = 7$

- $f_2(x) = -3x$

- $f_3(x) = 5x^2$

- $f_4(x) = -2x^2 + 4x$

- $f_5(x) = x^3$

- $f_6(x) = -x^3 + 6x$

- $f_7(x) = 3x^3 - 5x^2 + 2x - 7$

- $f_8(x) = -4x^2 + 8$

- $f_9(x) = 6x^3 - 3x^2 + 5$

- $f_{10}(x) = -2x^3 + x^2 - 7x + 9$
