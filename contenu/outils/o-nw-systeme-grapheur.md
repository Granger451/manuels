---
titre: Résoudre un système d'équations avec le grapheur
type: outil
---

1.  Aller dans l'application **« Grapheur »**.

    ![](images/numworks-comment-resoudre-un-syste-18.webp)

2.  **Saisir** les deux équations dans l'onglet « Expressions ».

    ![](images/numworks-comment-resoudre-un-syste-19.webp)

3.  Choisir **« Tracer le graphique »**.

    ![](images/numworks-comment-resoudre-un-syste-20.webp)

    Le résultat s'affiche dans l'onglet « Graphique ».

    ![](images/numworks-comment-resoudre-un-syste-21.webp)

4.  Rechercher les **coordonnées du point d'intersection** : se déplacer sur les droites jusqu'à leur intersection, les coordonnées s'affichent.

    ![](images/numworks-comment-resoudre-un-syste-22.webp)
